# MAPE-K-ELV-CRP-model
Agnostic MAPE-K decision model with learning and knowledge exchane capabilities.

This model has been developed in Anylogic Simulation Software
AnyLogic 8 University 8.9.7
Build: 8.9.7.202512010500 x64

This model has been developed as part of the dissertation for the PhD in Complexity Science at the ISCTE-IUL/ISTA in Lisbon, Portugal.
As a baseline for the use case, the Sterman Beer Game, the paper of Edali and Yasarcan (2014) has been used (https://www.comses.net/codebases/4161/releases/1.0.0/)
THe model has been developed with the FRAMESELF methodology and combines work of Kloes et al for Learning and Stacey et al for inter-agent knowledge exchange.
- Kloes: https://www.researchgate.net/publication/320367247_Parameterisation_and_Optimisation_Patterns_for_MAPE-K_Feedback_Loops
- Stacey: https://www.routledge.com/Complex-Responsive-Processes-in-Organizations-Learning-and-Knowledge-Creation/Stacey/p/book/9780415249195
